# 👕 NovaWear

NovaWear es una tienda online de ropa moderna desarrollada como proyecto personal para aprender y aplicar tecnologías de desarrollo web.

## 🚀 Tecnologías

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JavaScript
- Git
- GitHub

## 📂 Estructura del proyecto

```
NovaWear/

│── css/
│── html/
│── img/
│── js/
│── index.html
│── README.md
```

## 🎯 Objetivos

- Crear una tienda online moderna.
- Aprender desarrollo Frontend.
- Implementar un carrito de compras.
- Agregar autenticación de usuarios.
- Desarrollar un panel de administración.
- Integrar Spring Boot y MySQL.
